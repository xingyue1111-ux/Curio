## 测试步骤

### 1. 打开主页

http://localhost:3001 → 应该跟 Phase 1a 一样的画面（DEV 种子用户标 + Hi Yuri + 空状态 / 已有主题）。

### 2. 点底部「扔点东西进来」

弹出的 ActionSheet 现在**两个选项都是柠檬绿可点**：

- ✅ 「丢一张图进来」（**新激活**，描述：相机/相册/截图 · AI 看图识别）
- ✅ 「写一段文字」
- ⚪️ 「粘贴截图」（待开发）
- ⚪️ 「录一段语音」（待开发）

**注意**：图片选项被我放在第一位，因为你说这是高频场景。

### 3. 点「丢一张图进来」

弹出图片捕获 modal：

- 标题「你今天看到了什么？」
- 中间一大块虚线柠檬绿框「点这里选图」+ 说明文字
- 下面是「一句话批注 · 可选」输入框
- 底部「取消 / 让 AI 看看 →」

### 4. 选图

点中间的虚线框 → 系统弹出文件选择器。

**手机访问的话**会有：
- 拍照（直接调相机，因为 `capture="environment"`）
- 从相册选

**桌面浏览器**只会弹文件选择器，从本机选一张图。

**推荐第一张测试用什么图**：
- 截图：刚刚刷到的小红书 / 推特 / 微信聊天
- 海报 / 广告图（有文字，能看 OCR）
- 一张产品 UI 截图（你 PM 常用的）
- 任何带文字的图

选完后图片预览出现在虚线框位置，右上角有个 × 可以重选。

### 5. 加批注（可选）

下面那个输入框写一句话，比如：
- 「想看看 onboarding 怎么做」
- 「字体搭配参考」
- 「这家咖啡店的菜单设计」

**批注是关键的意图信号**，跟你之前文字捕获一样。

### 6. 点「让 AI 看看 →」

切到 processing step，**柠檬绿斜体字「Curio 正在看图…」+ 提示 5-10 秒**。

图片处理比文字慢，因为：
1. 先把图上传到 Supabase Storage（1-3 秒）
2. 调 DeepSeek-VL 看图（4-8 秒）
3. 生成 embedding（1 秒）

总共 6-12 秒之间。如果超过 30 秒还没结果，看终端 console 错误。

### 7. AI 结果（Review）

成功后切到 review step，应该看到：

- **顶部**：你提交的图的缩略图（最高 200px）
- **柠檬绿大卡片**：AI 写的一句简介 + 推测意图
- **暗色卡片**：AI 识别出来的文字（OCR）—— 如果图里有字
- **主题输入框**：AI 推荐的主题名（可改），新建主题会有「· 新建主题」标签
- 底部「← 改改 / 收进 Curio ✓」

**OCR 部分要重点验证**：
- 中文识别准不准
- 英文 / 数字识别准不准
- 排版乱不乱

### 8. 改主题（可选）+ 收进

不满意主题就改，满意就点「收进 Curio ✓」。

1 秒后 modal 关闭，主页自动刷新，主题列表更新。

## 重点验证项

| 项 | 你要观察什么 |
|---|---|
| 上传速度 | 1-3 秒能传完吗（取决于网速 + 图大小） |
| AI 看图质量 | 简介是否抓到核心、不是空泛 |
| OCR 中文识别 | 跟图里实际文字相比有多少错字 |
| OCR 英文识别 | 跟图里实际文字相比有多少错字 |
| 主题命名 | 跟你心里想的主题接近吗 |
| 总耗时体感 | 6-12 秒能忍吗、值不值 |
| 错误恢复 | 选错图能重选 / 失败能重试 |

---

## 可能踩的坑

| 症状 | 原因 / 解决 |
|---|---|
| 点「让 AI 看看」直接报 storage error | Storage bucket `curio-items` 没建 / 名字写错。回 Supabase Dashboard → Storage 检查 |
| ai_error: `xxx model not found` 等 | DeepSeek-VL 模型 ID 错。在 `lib/ai/deepseek.ts` 里 vl 是 `deepseek-vl`，如果你充的账号没开通 vl，要去 DeepSeek 控制台开通图片理解 |
| 图传上去但 AI 看不到（403） | signed URL 有问题。看终端 console 错误，告诉我 |
| 超过 30 秒 timeout | DeepSeek 当下慢 / 图太大。压一下图再传 |
| 中文 OCR 错字多 | DeepSeek-VL 中文 OCR 比专业 OCR 服务（百度/腾讯）略弱，可以接受小范围错。如果完全不能用，我们换百度 OCR 接进来 |

## 验证完成后告诉我

把以下 4 件事告诉我，决定下一步：

1. **整体跑通了吗** → 哪步卡
2. **AI 看图质量怎么样** → 给 1-5 分（1=瞎说 / 5=精准）
3. **OCR 准确度怎么样** → 给 1-5 分
4. **6-12 秒等待体感** → 能忍 / 太慢需要异步 / 还能再等

根据反馈我会决定下一步：
- 如果一切顺 → 接着做截图粘贴 + 语音 + Shortcuts
- 如果 OCR 不行 → 把百度 OCR 接进来做兜底
- 如果太慢 → 改成异步处理（立刻入库，AI 后台跑）
