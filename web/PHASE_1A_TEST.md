# Phase 1a 验证清单

> 文字捕获 MVP 跑通：从「扔一句话进来」到「主页看到主题」整链路。

## 启动准备（一次性）

### 1. 安装新依赖

```bash
cd web
pnpm install
```

新增了 `tsx`（跑 TS 脚本）和 `dotenv`（脚本读 .env.local）。

### 2. 创建种子用户（开发期跳过登录用）

```bash
pnpm seed:user
```

输出会有一行：

```
DEV_SEED_USER_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

复制这一整行，**追加到 `.env.local` 末尾**。

### 3. 重启 dev server

```bash
# Ctrl+C 停掉旧的
pnpm dev
```

## 验证流程

### 验证 A · 空主页（首次进入）

打开 http://localhost:3001

应该看到：

- 顶部柠檬绿小标 「· DEV · 种子用户身份」
- "Hi Yuri, 本月你最好奇的事"
- 数据 chip：「0 条本月 / 0 个主题」（没有「比上月」chip 因为没数据）
- 主题集合区显示空状态卡：「还是一片空白。点底下的『扔点东西进来』开始你的第一条好奇心收藏」
- 底部柠檬绿悬浮按钮「扔点东西进来」

**如果看到 4 张假数据主题（AI 产品交互 / 字体搭配 / 初创团队管理 / 生活观察）→ 说明 server component 没生效**，回看 `src/app/page.tsx` 是否已经改成 server component（不是 use client）。

### 验证 B · 扔第一条文字

1. 点底部「扔点东西进来」 → 从底部弹出 ActionSheet
2. 看到 4 个选项，**只有「写一段文字」是柠檬绿可点**，其他 3 个灰色不可点
3. 点「写一段文字」 → ActionSheet 关闭，弹出捕获 modal
4. 标题：「你今天好奇了什么？」
5. textarea 里写一段话，比如：

   ```
   今天看到 Linear 的 Cmd+K，发现它把所有命令都收纳到一个地方，
   按 K 弹出来，搜索任何动作。这是一种渐进式引导的设计。
   ```

6. 一句话批注框（可选）填：

   ```
   AI 产品 onboarding 设计的参考
   ```

7. 点「让 AI 看看 →」

### 验证 C · AI 处理 + 确认

8. 应该看到 2-3 秒的 loading：「Curio 正在打理…」
9. AI 返回后切到 review step，应该看到：
   - 柠檬绿大卡片：AI 写的一句简介（30 字内）
   - 简介下面：AI 推测的「为什么记」
   - 「归到主题」输入框：填 AI 建议的主题名（比如「AI 产品交互」），可能带「· 新建主题」标签
10. 主题名可以改（不满意 AI 建议就改成你想要的）
11. 点「收进 Curio ✓」 → 进入 saving step
12. 1 秒后看到 「✓ 收好了 · 归到『XX』」
13. modal 自动关闭，**主页应该刷新**显示这条 item 归到的主题

### 验证 D · 主页显示新主题

回到主页：

- 数据 chip：「1 条本月 / 1 个主题」
- 主题集合区出现 1 张柠檬绿 feature 卡：「01 · 你刚定的主题名 · since X 月 Y 日 · 0 天 · 1」

### 验证 E · 扔第二条到同一主题

再扔一条相关内容，AI 应该认出是同一主题，主题名直接复用（`suggested_topic_is_new: false`），不会创建新主题。

主页应该显示主题卡的数字 +1 = 2。

### 验证 F · 扔第三条到新主题

写一段完全不同方向的内容，比如：

```
看到一家很特别的咖啡店，门口写「不卖给戴墨镜的人」，
反向筛选客户的有趣手法。
```

AI 应该建议一个新主题（比如「生活观察」），标签显示「· 新建主题」。

主页应该出现第 2 个主题卡。

## 可能踩的坑

| 症状 | 原因 / 解决 |
|---|---|
| 打开主页跳到 `/login` | 没配 DEV_SEED_USER_ID 或 .env.local 没保存。检查 `pnpm seed:user` 是否成功，UID 是否填进 .env.local，重启 dev |
| 点提交后报 `ai_error` | DeepSeek API key 错 / 没余额。检查 DEEPSEEK_API_KEY |
| 点提交后报 `db_error` | Supabase migration 没跑全。回看 Table Editor 看 items / topics 表是否存在 |
| AI 处理超过 30 秒 timeout | DeepSeek 当下慢 / 网络问题。重试一次 |
| `embedding_expired` 报错 | draft 后超过 5 分钟才点确认。重新提交即可 |
| 主题名字带奇怪字符 / 重复主题 | AI 推的主题名 slug 化冲突。先手动改主题名再确认 |

## 验证完成后告诉我什么

1. **整个链路跑通了吗**？哪一步卡住了？
2. **AI 的主题命名质量怎么样**？（合理 / 太宽泛 / 太具体 / 奇怪）
3. **AI 的简介准不准**？
4. **「让 AI 看看 → 看到结果」这 2-3 秒等待感觉怎么样**？还能忍还是太久？

这 4 个反馈决定 Phase 1b 怎么调（要不要继续保持同步处理 / AI prompt 要不要改 / 主题命名约束要不要加）。

Phase 1a 跑通后下一步进 Phase 1b（图片 + 截图 + 语音 + 列表/搜索接真实数据）。
